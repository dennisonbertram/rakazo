The Hex tile shows only in the macOS desktop app, or on any surface once a Hex connection exists ("On web": read-only status, no actions but Disconnect). Disconnect opens the existing confirm dialog with "Delete imported meetings too". "Meetings off in Hex" cannot be told apart from zero meetings, so it has no state. Hex has no account, so there is no key field.

Settings → Voice

Voice

Providers

Downloading · 42%

Extends the existing VoiceSettingsOverlay provider list with two entries. "On this device" appears only in the macOS desktop app when the Hex executable is found; its model list comes from Hex's models.list() (names here are examples). Preparing a model is the only download, and it is explicit. "OpenAI-compatible" stores base URL, key and model in the user's voice credential (no environment variable). The selected transcription provider is used for dictation and server-side meeting transcription; there is no separate meeting setting.
