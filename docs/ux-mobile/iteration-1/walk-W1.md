# Mobile walk W1: Calendar, Mail, journeys 01 and 03

Walker W1, session mob1-W1, mock-data demo stack, Maya (mock founder). Viewport 393x852 at device scale 3 (iPhone 16 profile), spot checks at 375x812 and landscape 844x390. Touch emulation: the CLI device profile alone did not set `pointer: coarse`; it was forced through CDP touch emulation and then confirmed (`pointer: coarse` true, `hover: none` true, 5 touch points), so touch-target measurements are valid. The CLI mouse click hung under touch emulation, so taps were issued as DOM `click()` calls; tap counts below are counted as the taps Maya would make. Screenshots are kept outside the repo (file names quoted below). No console or page errors were seen on any walked screen. Horizontal page overflow was 0 px on every screen walked.

Not exercised: real Google data, the passkey and OAuth flows, sending to a real address (two test mails to an invented .test address were sent and one undo window was timed), approving the seeded background approval (shared with other walkers), saving the Watch routine.
