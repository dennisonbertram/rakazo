# Visual inspection V1: Calendar, Inbox, Activity, approvals (phone)

Inspector session: mob1-V1. Target: mock-data demo stack (web 5379). Date: 2026-10-27.
Method: iPhone-16 device profile plus CDP touch emulation. Confirmed `pointer: coarse` = true and `hover: none` = true at 390x844, 375x812, 844x390 and 768x1024 (device scale 3). Each state was screenshotted and measured with `layout-audit.js`, `geometry-audit.js` and a visible-target rect pass. External second-opinion script skipped as instructed. Screenshot names below are the files kept in the inspector's scratch folder (outside the repo).

Limits (stated plainly):
- The machine load was very high (load average above 20), so UI responses took 2 to 15 seconds and the browser crashed once. I did not treat latency as a finding.
- Not exercised: Track, attachment "Review with AI", the "Send now" button on a draft, the urgent-mail table in chat, Day view with events, the Calendar "Waiting on you" panel and the Activity "Waiting on you" section (this account had no items when I looked), the Calendar empty state ("Nothing scheduled", `Calendar.tsx:494`), approval-toast expand, and the Activity filter row. Opening a second mail row by tap stopped working late in the session, so those flows are open.
- I clicked Allow on the AI-sharing consent card in the Inbox agent chat to get a draft. This is a mock account setting; other walkers on the shared account will see Inbox grouped into "Needs reply" and "To do" afterwards. I also created one draft-reply approval card and sent one mock message ("Undo toast check") to an invented address.

## Excellent as is

- All header, tab, view-switch, filter and toast buttons measured at least 44 px with coarse pointer on (Calendar, Inbox, drawer). No sideways page scroll anywhere.
- Inbox row layout on a phone: two-line rows of 64 px, a 44 px select target, one "..." overflow button replacing hover actions (owner decision upheld), unread dot and bold sender.
- The Schedule view: grouped by day, 44 px rows, bot avatar and name right-aligned, today-first; the best Calendar view on a phone.
- The Mail approval card in the agent chat: From, To, subject, "Show more", Send and Discard at 44 px, with the reason line ("Asked because of your rule for Send email").
- The compose sheet: single column, From, To chips, Cc/Bcc, Subject, body, and a bottom bar with a pill Send; recipient chips and "Draft saved" status are clear.
- Approval toast copy and size (one line, 52 px, 44 px dismiss) and its wrap to two lines at 375 px.
- The tablet (768) calendar and inbox: columns, badges (Urgent, Important, Action, To do date) and the week grid all fit with no changes needed.
- The approvals list in bot settings: label left, select right, 44 px rows (apart from V1-17 clipping).
